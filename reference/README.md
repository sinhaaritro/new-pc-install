# Reference

Living reference docs — the authoritative, lookup surface of current system
truth (living, version-pinable; no DRAFT/APPROVED lifecycle). Distinct from
`docs/specs/` (what to build, lifecycle) and `docs/decisions/` (why we chose,
immutable, backlinked).

ID convention: `<slug>.md` (no numeric prefix; the filename is the single
identity). Display title comes from the filename or H1, never a `name:` field.

Version pin (opt-in): `version_pin: <git-tag>` (primary) or `fallback_pin:
<commit-hash>` (when no tag exists). Absent by default; when present the value
must be a real tag / reachable commit.
