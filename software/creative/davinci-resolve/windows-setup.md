# DaVinci Resolve Setup (Windows)

## Download **DaVinci Resolve Studio** (or Free) from the Blackmagic Design website.
## Install the application, accepting the default database location.
1. Open the install software.
2. Go through the quick steps
3. Select 1080p HD
4. Create a folder DaVinci_System in the root. Use this as the project location
    *   *> Unlike Microsoft Word or Affinity Photo, DaVinci Resolve doesn't just save a simple project file right away. It creates a "Database" (now called a Project Library) and generates invisible cache files to help videos play smoothly. If you put this in actual project folder, that folder will quickly get cluttered with weird-looking system folders.
    *   *> This new folder (D:\DaVinci_System) is only for the software's internal files, memory, and cache. You will rarely ever need to look inside this folder yourself.
5. Every porject needs to be exported out to be saved properly.
6. Clost DaVinci and open again, now you will be taken to project manager
7. Create new project
