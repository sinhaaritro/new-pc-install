# Docs

Human + AI shared space: the committed knowledge of this repository.

| Folder | Holds | ID convention |
| :--- | :--- | :--- |
| `specs/` | What to build — permanent functional & technical specs with a lifecycle (DRAFT → APPROVED) | `NNN-<slug>.md`, sub-IDs `NNN-<letter><NN>` |
| `decisions/` | Why we chose — immutable ADRs, backlinked to specs | `adr-<NNN>-<slug>.md` (flat, never nested) |
| `reference/` | What is — living, lookup, authoritative docs (no lifecycle) | `<slug>.md` |
| `temp/` | Ephemeral working memory (gitignored; purged by task-cleaner) | none |

## Frontmatter conventions

- `tags: [lowercase-kebab, ...]` on every doc in `specs/`, `decisions/`,
  `reference/` (governed by `promote_spec.py tag-lint`, also inside `check`).
- Optional on `reference/` only: `version_pin: <git-tag>` or `fallback_pin:
  <commit-hash>` (validated when present).
- The filename is the single identity — no `name:` field anywhere.
